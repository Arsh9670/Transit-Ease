# TransitEase — Smart Public Transportation Platform

## Overview
TransitEase is a front-end prototype for a public transit commuter portal. It demonstrates route planning, schedules, crowd estimates, service alerts, and prototype ticket booking.

## Run
Open `index.html` in a modern browser. Internet access is needed for the external Google Fonts and JSZip CDN scripts.

## Pages / sections
- Dashboard: overview cards, popular routes, latest alerts, quick actions.
- Journey Planner: enter origin, destination, date/time; compare simulated route options; select and book a demo ticket.
- Schedules: filter simulated transit timetables by Bus, Metro, or All.
- Crowd Status: display simulated occupancy percentages and crowd categories.
- Alerts & Holidays: filter service advisories, disruptions, and normal-service notices.
- My Tickets: view/cancel locally saved prototype tickets.

## Important
This is demo/prototype data, not a live transit system. Ticket records are stored in browser LocalStorage and are not real fare tickets. Crowd levels, schedules, and alerts are simulated.
